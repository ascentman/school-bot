# Пільгові категорії учнів

Довідник категорій, за якими протягом навчального року збирається інформація.
Джерело — перелік, наданий соціальним педагогом школи (м. Львів).

Це **джерело правди** для довідника категорій у фічі 2 (реєстр учнів).
Ключі в лівій колонці — майбутні значення enum у коді; змінювати їх після
запуску не можна, бо вони потраплять у БД.

| Ключ | Категорія |
|---|---|
| `ORPHAN` | Діти-сироти та діти, позбавлені батьківського піклування |
| `SEN_INCLUSIVE` | Діти з особливими освітніми потребами, які навчаються в інклюзивних класах |
| `LOW_INCOME` | Діти із сімей, які отримують допомогу згідно із Законом України «Про державну соціальну допомогу малозабезпеченим сім'ям» |
| `WAR_VETERAN_FAMILY` | Діти з числа осіб, визначених у статтях 10 і 10¹ Закону України «Про статус ветеранів війни, гарантії їх соціального захисту» |
| `COMBATANT_CHILD` | Діти учасників бойових дій |
| `WAR_DISABILITY_PARENT` | Учні з числа дітей осіб з інвалідністю внаслідок війни |
| `DISABILITY` | Діти з інвалідністю |
| `DIGNITY_REVOLUTION` | Учні з числа дітей постраждалих учасників Революції Гідності та Героїв Небесної Сотні |
| `LARGE_FAMILY` | Діти з багатодітних сімей |
| `COVID_MEDIC_ORPHAN` | Діти працівників закладів охорони здоров'я, померлих внаслідок коронавірусної хвороби (COVID-19) |
| `IDP` | Учні із числа внутрішньо переміщених осіб |
| `WAR_AFFECTED` | Учні, які мають статус дитини, що постраждала внаслідок воєнних дій і збройних конфліктів |
| `CAPTIVE_MISSING_DEFENDER` | Учні з числа дітей Захисників та Захисниць України, які перебувають у полоні або зникли безвісти |
| `CHORNOBYL` | Учні з числа осіб, які постраждали внаслідок Чорнобильської катастрофи |

Усього 14 категорій.

---

## Що з цього випливає для схеми БД

**1. Категорій в учня може бути кілька одночасно.**
Дитина може бути водночас ВПО, з багатодітної сім'ї та з інвалідністю. Тому це
**не** одне поле-enum на учня (як було накидано в початковому плані), а окрема
таблиця звʼязків «учень ↔ категорія».

```
student_benefit
  student_id, category, document_no, valid_from, valid_until,
  confirmed_at, confirmed_by, note
  UNIQUE(student_id, category)
```

**2. Кожна категорія підтверджується документом.**
У переліку прямо зазначено «відповідно до поданих довідок з відділів соціального
захисту». Довідки мають номер і термін дії, тому потрібні `document_no`,
`valid_from`, `valid_until` — інакше неможливо відповісти, чи пільга ще чинна
на дату перевірки.

**3. Категорії зʼявляються протягом року, а не лише 1 вересня.**
Родина отримує статус ВПО в листопаді, довідку про малозабезпеченість — у січні.
Тому потрібна історія змін (`student_benefit_history`), а звіт має будуватися
**станом на дату**, а не «як зараз».

**4. Це чутливі персональні дані неповнолітніх.**
Категорії на кшталт `ORPHAN`, `DISABILITY`, `CAPTIVE_MISSING_DEFENDER` —
особливо чутливі. Потрібні шифрування БД, рольовий доступ і лог того, хто які
записи переглядав. Проєктується до старту фічі 2, не докручується потім.

## Типові звіти, які знадобляться

- Списки по кожній категорії окремо (найчастіший запит).
- Зведення «категорія × клас» — скільки дітей у кожній паралелі.
- Учні з кількома категоріями.
- Довідки, термін дії яких спливає найближчим часом — щоб вчасно попросити оновити.
- Перетин із безкоштовним харчуванням: пільгова категорія зазвичай дає право на
  безкоштовне харчування, тож цей довідник звʼязується з фічею 1.
